# T005 Contracts Handoff — Domain, SQLite, Jobs, and API Foundation

Verdict: PASS

## Scope

Implemented the T005 board card for the ZANA Core shared domain contracts,
deterministic SQLite lifecycle, Alembic migrations, real repositories and
unit-of-work CRUD, persistent job/event state with cancellation-safe
transitions, and authenticated API registration. Only owned paths were
touched: `core/pyproject.toml`, `core/alembic.ini`, `core/migrations/**`,
`core/zana_core/{domain,db,jobs,api}/**`, `core/zana_core/main.py`,
`core/tests/{domain,db,jobs,api}/**`, and this handoff.

- `core/pyproject.toml` — added `alembic>=1.14,<2` and `sqlalchemy>=2.0,<3`.
- `core/alembic.ini`, `core/migrations/env.py`, `core/migrations/script.py.mako`,

- `core/zana_core/domain/enums.py` — canonical enums grounded in specs:

  WAL/foreign-keys/busy-timeout engine pragmas; Alembic-driven `Database`

- `core/zana_core/jobs/{state_machine,services}.py` — exact build lifecycle
  transitions and generic job transitions, terminal immutability,

- `core/zana_core/api/{schemas,errors,deps,doctor,runtimes,models,capabilities,builds,jobs,images}.py`
  and `core/zana_core/main.py` — typed Pydantic models, canonical errors,

- `core/tests/{conftest,api,db,jobs}/**` — 37 focused tests replacing the old
  local `api/conftest.py` fixture scope with isolated temp databases.

## Interface facts

- Frozen `GET /api/v1/health` contract is preserved and still covered by the
  existing auth/shape tests.
- New authenticated endpoints, all requiring the per-launch bearer token:
  `GET /api/v1/runtimes`, `POST /api/v1/runtimes/manual`,
  `DELETE /api/v1/runtimes/{id}`, `GET /api/v1/models`,
  `GET /api/v1/models/{key}`, `GET|POST /api/v1/capabilities`,
  `GET|PUT /api/v1/capabilities/{id}`, `POST /api/v1/builds/analyze`,
  `GET /api/v1/builds/{id}`, `POST /api/v1/builds/{id}/cancel`,
  `GET /api/v1/jobs/{id}`, `GET /api/v1/jobs/{id}/events`,
  `GET /api/v1/images`, `GET /api/v1/images/{digest}`,
  `GET /api/v1/system/doctor`.
- `POST /api/v1/builds/analyze` validates real capability/model records and
  persists a `DRAFT` build job with honest `ANALYSIS_NOT_STARTED` state; no
  fake analysis progress is emitted.
- Contract endpoints needing runtime adapters are intentionally not registered
  yet: runtime refresh/probe, model pull, capability source ingestion,
  build approve/execution, image verify/export/import, instance lifecycle,
  chat/SSE, and baseline/candidate evaluation. They are deferred to the
  runtime/build lanes rather than returning fake success.

## Security delta

- Per-launch bearer auth is unchanged and still constant-time; all new routes
  are protected by it.
- Runtime manual endpoints reject embedded credentials in URLs.
- No secrets, tokens, or demo rows are persisted; the database starts empty.
- DB file creation defaults to the OS user data directory via `platformdirs`,
  and tests always use isolated temp paths.

## Residual risk

- `core/uv.lock` is PM-owned and was intentionally not regenerated here; the
  PM must run `uv lock --project core` (or `uv sync`) to record the new
  `alembic`/`sqlalchemy` dependencies before merging.
- The Core `create_app` now opens/migrates SQLite on startup; the frozen
  sidecar CLI surface is unchanged, so desktop packaging is unaffected, but
  integration should rerun the bundled-app smoke.
- Generic job events are stored for `jobs`; build jobs persist status history
  in `build_jobs` without a separate event table, matching the current spec.
