## Security delta

- **Auth**: HMAC constant-time comparison via `hmac.compare_digest` on the
  per-launch bearer token. No timing side-channel on token comparison.
- **Token handling**: Token lives only in the module-level `ServerConfig`
  struct. Never logged, persisted, or echoed in responses.
- **CORS**: Strict allowlist — `http://127.0.0.1`, `http://localhost`,
  `tauri://localhost`, `https://tauri.localhost` only.
- **Error responses**: No raw tracebacks. Catch-all handler returns generic
  `INTERNAL_ERROR` envelope. 401 responses use the canonical error shape.
- **No telemetry**: No Sentry SDK, analytics, or phone-home code present.
- **No open docs**: `docs_url=None, redoc_url=None, openapi_url=None`.
- **Loopback enforcement**: CLI rejects non-loopback host values.

## Interface contract (frozen)

- `GET /api/v1/health` bound to `127.0.0.1:<port>`
- `Authorization: Bearer <token>` required; exact match via hmac
- Missing/empty/wrong/malformed → `401` with `{"error": {"code": "UNAUTHORIZED", ...}}`
- Valid → `200` with `{"status": "ok", "version": "<semver>", "python_version": "3.12.x", "pid": <int>, "uptime_seconds": <float>}`

**Desktop lane receives**: connection data via Tauri invoke → calls
`http://127.0.0.1:<port>/api/v1/health` with `Authorization: Bearer <token>`.

**No deviation from contract.**
