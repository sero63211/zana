## Honesty contract

Only Core health is real. Every other surface reports unavailable, empty, or
not-connected state instead of inventing records, runtimes, capabilities,
images, instances, or success. Disabled user-controlled actions show exactly
which precondition is missing. The Core token is never rendered, persisted, or
logged by the UI.
